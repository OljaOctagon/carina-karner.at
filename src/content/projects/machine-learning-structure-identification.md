# Machine Learning for Structure Identification

Geometric learning for local order and crystalline structures.

This project develops machine learning approaches for identifying and classifying local structural order in particle-based simulations. By combining geometric descriptors with supervised and unsupervised learning, we aim to automate the detection of crystalline phases, defects, and novel structures in complex particle systems.
