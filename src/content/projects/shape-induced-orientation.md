# Shape-Induced Orientation Phase within 3D Nanocrystal Solids

When nanocrystals self-assemble into ordered superstructures, the positional and orientational order determines the properties of the resulting solid. This project explored how particle shape can drive orientation phase transitions in three-dimensional nanocrystal assemblies.

## Key Results

- Discovered shape-induced orientation phase transitions in 3D nanocrystal solids
- Combined experimental SAXS measurements with particle-based simulations
- Mapped phase diagrams as a function of particle shape anisotropy

## Publication

Karner, C., Burian, M., Yarema, M., et al. "A Shape-Induced Orientation Phase within 3D Nanocrystal Solids." *Advanced Materials* (2018).
